WHEN CREATING THE ZIP FILE:
===========================

INCLUDE THESE (Required):
-------------------------
✓ Click2Serve/ folder (entire Laravel app)
✓ print-service/ folder (without node_modules)
✓ chatbot-service/ folder (without node_modules)
✓ docs/ folder
✓ All .bat files in Click2Serve/Click2Serve/

EXCLUDE THESE (To reduce ZIP size):
-----------------------------------
✗ Click2Serve/Click2Serve/vendor/  (~150MB - will reinstall with composer)
✗ print-service/node_modules/       (~50MB - will reinstall with npm)
✗ chatbot-service/node_modules/     (~30MB - will reinstall with npm)
✗ Click2Serve/Click2Serve/storage/logs/*.log (optional)
✗ Click2Serve/Click2Serve/storage/framework/cache/*
✗ Click2Serve/Click2Serve/storage/framework/sessions/*
✗ Click2Serve/Click2Serve/storage/framework/views/*

IMPORTANT - DO NOT EXCLUDE:
---------------------------
! Click2Serve/Click2Serve/.env (contains your API keys and settings)
! Click2Serve/Click2Serve/storage/app/public/* (uploaded files)


ON THE NEW DEVICE:
==================

1. Extract ZIP to: C:\xampp\htdocs\
   (So you have: C:\xampp\htdocs\Click2Serve\Click2Serve\)

2. Install prerequisites:
   - XAMPP: https://www.apachefriends.org/
   - Composer: https://getcomposer.org/
   - Node.js: https://nodejs.org/

3. Start XAMPP (Apache + MySQL)

4. Run setup scripts (in this order):
   
   Step A: Install dependencies
   Double-click: Click2Serve\Click2Serve\setup-new-device.bat
   
   Step B: Create database
   Double-click: Click2Serve\Click2Serve\FRESH_SETUP.bat

5. Start all services:
   Double-click: Click2Serve\Click2Serve\start-click2serve.bat
